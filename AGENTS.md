# FORM — Agent instructions

## Source-First UI Preview Protocol

- Before recreating any existing FORM interface, inspect the latest relevant HTML, CSS, JavaScript, theme tokens, runtime state and responsive rules on the authoritative branch. Do not rely on memory or previous mockups.
- Provide interactive UI previews directly in chat where supported, with portrait and actual adaptive landscape layouts. Do not merely stretch portrait layouts.
- Preserve existing components, labels, measurements, colors, behavior and empty states. Never invent existing interface elements or sample data. Use demo data only when explicitly requested.
- Clearly distinguish source-derived previews from proposed designs. Disclose approximations, unverified runtime behavior and source access limitations. Never claim pixel-perfect or live verification without evidence.
- Preview requests are read-only. Modify application code only upon explicit approval.
- Preserve the existing global design system and follow the established development and validation workflow.
